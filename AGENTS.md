# Repository instructions

- Commit every change to this repository immediately after making and verifying it.
- Do not ask the user for permission or confirmation before creating the commit.
- Keep each commit scoped to the change just completed and use a descriptive commit message.

## Wayfinder

- The repository's active Wayfinder map is `WAYFINDER.md` at the project root.
- A bare `/wayfinder` invocation means resume and work through that map; do not ask for a new destination unless the user explicitly requests a new map or a changed destination.
- Child tickets live in `.scratch/intl-locale-for-php/issues/` and use their `Status` and `Blocked by` fields to determine the frontier.
