# Instructions

When `/wayfinder` is invoked without another map, resume the active map in `WAYFINDER.md`.

Make repository changes on a branch and deliver them through a pull request. Keep the default branch unchanged until the pull request is merged.

## Agent skills

### Issue tracker

Issues live in the private GitHub repository `MidnightDesign/locale-php`; external pull requests are not a triage request surface. See `docs/agents/issue-tracker.md`.

### Triage labels

The standard five-role triage vocabulary is used unchanged. See `docs/agents/triage-labels.md`.

### Domain docs

This is a single-context repository. See `docs/agents/domain.md`.
