# locale-php

Planning workspace for a PHP implementation of ECMAScript `Intl.Locale` semantics.

The canonical planning artifact is the [Intl.Locale for PHP Wayfinder map](https://github.com/MidnightDesign/locale-php/issues/1). The root-level [WAYFINDER.md](WAYFINDER.md) is its local pointer.

No production implementation has been started. The Wayfinder map is intentionally decision-first: resolve its frontier before turning the result into implementation tickets.
