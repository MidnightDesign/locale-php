# Domain docs

This is a single-context repository.

Before exploring the project, read `CONTEXT.md` at the repository root and any relevant ADRs under `docs/adr/`. If either location does not exist, proceed silently.

Use the glossary's defined vocabulary in issues, decisions, tests, and implementation plans. Avoid synonyms that the glossary explicitly rejects. Surface any conflict with an existing ADR instead of silently overriding it.
